Connect your AI agent to RogueIQ

Your agent gets official U.S. money releases and a net worth by age calculator, each answer carrying its source, date and disclaimer. Free, read-only, no sign-up or API key.

Quick setup

Add both MCP servers to any client that supports remote MCP over streamable HTTP (Claude, Cursor, ChatGPT connectors and others).

{
  "mcpServers": {
    "rogueiq-wire": { "url": "https://rogueiq.com/wire/mcp" },
    "rogueiq-networth": { "url": "https://rogueiq.com/net-worth-by-age/mcp" }
  }
}

Claude Code:

claude mcp add --transport http rogueiq-wire https://rogueiq.com/wire/mcp
claude mcp add --transport http rogueiq-networth https://rogueiq.com/net-worth-by-age/mcp
